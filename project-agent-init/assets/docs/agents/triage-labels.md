# Triage 标签

工程 skills 以五个标准 triage 角色说话。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全规格化，可交给 AFK agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施（含留待用户手测/现场验证的票） |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色（如"打上 AFK-ready triage 标签"），使用本表对应的标签字符串。

如需改用其他标签词表，编辑"本仓库 tracker 中的标签"列即可。
